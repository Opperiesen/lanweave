# Brand

## Name

**Lanweave** describes the product's purpose without borrowing the controller
vendor's identity: it weaves local network intent, live state and operator
review into one workflow.

The repository and package use `lanweave`; the controller-specific integration
is described as a UniFi adapter.

## Mark

The mark is a minimal W assembled from four alternating segments. Their weave
represents declared intent and live network state meeting inside one reviewed
control path. The deep-navy field represents the local safety boundary.

The geometry is deliberately vendor-neutral and remains recognizable at small
sizes. Do not add nodes, controller symbols, gradients or Ubiquiti and UniFi
marks.

## Lockup

The canonical lockup contains only the woven W and the Lanweave wordmark. Its
fixed deep-navy field keeps the same contrast on light and dark surfaces.

Keep clear space around the lockup equal to the stroke width of the mark. Do
not stretch, rotate, recolor, add a tagline or detach individual segments.
