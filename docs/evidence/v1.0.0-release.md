## Verified gates

The release workflow passed required CI on Python 3.11, 3.12, 3.13 and 3.14,
the optional MCP matrix, locked dependency and GitHub Actions audits, wheel and
source-distribution builds, and clean installation of both distributions on
each supported Python version. The installed MCP extra exposed its console
entry point and imported successfully.

The public verification workflow passed the annotated tag and target commit
check, GitHub Release and asset check, SHA256 checksums, PyPI file and digest
check, GitHub artifact attestation, and PyPI PEP 740 attestation verification
for both the wheel and source distribution.

The initial release workflow had a post-publication configuration defect: its
metadata step did not pass `GH_TOKEN` to `gh`. The defect was fixed in
[PR #161](https://github.com/Opperiesen/lanweave/pull/161), and the rerunnable
verification workflow above provides the successful final evidence without
republishing or changing the immutable v1.0.0 tag.
