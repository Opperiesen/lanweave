## Porte de mutation autorisée

- Authorized NAT lifecycle: passed
- Run protégé : [31907918542](https://github.com/Opperiesen/lanweave/actions/runs/31907918542)
- Versions publiques : UniFi Network `10.5.67` et UniFi OS `5.1.19`
- Mode : `local-classic-session`
- Résultat : create, update, protected prune et delete d'un mapping désactivé
  réussis, avec inventaire final propre

La porte est désactivée par défaut. Elle exige l'input workflow NAT dédié, la
confirmation `I_UNDERSTAND`, un préfixe `lanweave-ci-*`, les credentials
session dédiés et un environnement protégé. Les ressources sont relues avant
suppression et le test refuse de réutiliser une cible existante.

Le contrôleur testé ne renvoie pas de métadonnée d'origine pour les mappings
NAT. Lanweave conserve donc l'ID créé ou mis à jour comme preuve de propriété
uniquement pendant la session courante; un nouveau processus traite la même
ressource comme `UNKNOWN` et la protège. Aucun host, site, credential, nom de
mapping, payload ou détail de topologie ne doit apparaître dans cette preuve.
