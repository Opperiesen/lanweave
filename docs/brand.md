# Brand

## Name

**Lanweave** describes the product's purpose without borrowing the controller
vendor's identity: it weaves local network intent, live state and operator
review into one workflow.

The repository and package use `lanweave`; the controller-specific integration
is described as a UniFi adapter.

## Mark

The mark is a small network graph with several interlaced paths. The nodes
represent resources and the paths represent the plan that connects desired
state to live state. It is intentionally geometric and vendor-neutral; do not
add Ubiquiti or UniFi marks to it.

The canonical source is [assets/logo.svg](../assets/logo.svg). It is an
original project asset and may be used under the repository's Apache-2.0
license.
