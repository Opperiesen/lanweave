# Evidence v0.7.0 — VPN

## Offline fixture gate: passed

The v0.7.0 contract, normalization, secret boundary, export, read-only plan
observation, CLI and MCP surfaces are covered by the repository test suite and
`scripts/verify_v070_evidence.py`.

## Read-only VPN evidence: fixture-backed

The fixtures cover paginated VPN server and site-to-site tunnel overviews,
connected VPN peers, an empty response and a malformed response. No fixture
contains credentials, private keys, generated profiles or raw authorization
headers.

## Live VPN evidence limitation: documented

The designated controller is not used to claim a live VPN lifecycle in this
release. Its current network design does not provide an active VPN resource to
exercise safely, and v0.7.0 deliberately contains no VPN mutation path. A
future protected read-only run may set `LANWEAVE_REQUIRE_V070_LIVE_EVIDENCE` only
after the controller version and endpoint coverage are recorded in the
compatibility report.
