## Porte contrôleur en lecture seule

- Read-only firewall evidence: pending protected workflow run

La porte lit les zones, groupes, règles et ordres officiels, puis vérifie un
export portable sans IDs ni métadonnées. Le rapport d'exécution publié doit
rester limité aux versions déclarées et aux résultats de tests.

## Porte de mutation autorisée

- Authorized firewall lifecycle: pending protected workflow run
- Scope: groupes et règles désactivées, préfixe unique `lanweave-ci-*`
- Opérations couvertes: create, update, reorder, delete
- Compte: clé API dédiée de l'environnement protégé

La porte est désactivée par défaut. Elle exige l'input workflow correspondant,
la confirmation `I_UNDERSTAND`, un préfixe `lanweave-ci-*` et un environnement
protégé. Les ressources sont relues avant suppression et le test refuse de
réutiliser un préfixe existant.

Une release stable ne peut être publiée que lorsque les deux lignes live sont
remplacées par `passed` et que les liens vers les rapports GitHub sont ajoutés
ici. Tant que ce n'est pas le cas, la preuve v0.5 reste incomplète.
